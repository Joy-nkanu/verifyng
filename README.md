# VerifyNg

In Nigeria there are a lot of fake products and it’s so hard to verify this products to see if they are real especially consumables. I want to build a website that simply allows you scan the product barcode or any way you can use to verify the authenticity of this product.  When scanned show the production date expiry date  and every vital information to show the product are original
